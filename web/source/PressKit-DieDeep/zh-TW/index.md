# 概述

***當一切被深淵吞噬殆盡，戰鬥，只為確認心臟仍在跳動***

**《死深 Die Deep》是一款聚焦純粹敵我對峙的動作遊戲。**  
沒有地圖探索、解謎或冗餘要素，唯一的核心，就是「戰鬥」！
仔細觀察敵人的動作，捕捉破綻、制定戰略並精準出擊，一次魯莽的進攻或貪刀，就足以換來致命的失敗。
操控擁有各自目標與特色的角色，在不斷的激戰中追尋那股能改寫命運的神秘之力，進入深淵，直面死亡。

---
# 世界

當一切被深淵吞噬殆盡，所有的渴望都已化為塵埃。遊蕩的靈魂早已忘卻了追求的本能，也遺忘了活著的理由。
直到深淵發出無聲的召喚，引誘著來者深入，探尋那已被遺忘的，你曾經最真實的渴望。
哪怕這可能只是一個誘騙獻祭的謊言，但在這片令人窒息的虛無中，尋找謊言也比面對空洞的永恆更有價值。
下降吧！向著深淵的盡頭，只為親手觸碰那唯一的希望。  
戰鬥吧！只為確認心臟仍在跳動。

# 特點
+ **純粹敵我對峙的戰鬥體驗**
專注觀察敵人的動作，抓住每一個行動的契機。謹慎制定戰略並精準出擊，隨意攻擊或貪刀都可能導致致命後果。但這並不意味著角色動作緩慢笨拙，他們擁有敏捷的身手和強大的技能，讓你在冷靜應戰中發揮淋漓盡致。
	
+ **風格特異的操作角色**
擅長格擋的獨眼戰士，或是手持雙刃的凌厲盜賊，每位角色都有截然不同的戰鬥風格。深入挖掘他們的特性，發揮每位角色的優勢，找到屬於你的制勝之道。

+ **充滿挑戰性的魔王**
直面風格迥異的深淵強敵，任何一次誤判都將招致瞬間的毀滅，唯有完美應對才能存活。

+ **緊湊刺激的連續戰場**
隨著地形自動變化，戰鬥將持續不斷襲來。你必須抓住每一絲喘息的機會來恢復，突破一場又一場的挑戰

+ **構築多變的戰鬥風格**
透過勝利獲得靈魂能量，不斷成長。搭配多樣化的魂符與技能，打造自己的專屬戰鬥風格
